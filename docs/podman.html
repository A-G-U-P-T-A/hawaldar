Podman

Hawaldar requires a container engine. Tools never run on the host. If Podman is missing, scans do not start.

In-app setup

Use Set up Podman in Runtime (or Settings → Runtime). That is the supported path — not a wiki of copy-paste commands.

  • Windows — winget or the official MSI. Needs WSL or Hyper-V. A UAC prompt is normal. Hawaldar does not silently install Podman.
  • macOS — installs Podman and starts the machine VM.
  • Linux — locates an existing engine. No sudo package install from the app.

Docker

If Docker is already installed, you can choose Use Docker instead. Hawaldar does not install Docker Desktop.

Workspace

Tool containers bind-mount ~/.hawaldar/workspace at /workspace. Drop pcaps and source there. Images are pulled on demand after HITL approval.
