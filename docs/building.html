Building from source

The app lives in hawaldar-app/. Node 22+ is required. scripts/ensure-electron.mjs downloads electron.exe because Electron 43 has no npm postinstall.

Windows

git clone https://github.com/A-G-U-P-T-A/hawaldar.git
cd hawaldar\hawaldar-app
scripts\setup.bat
scripts\dev.bat

Daily work is scripts\dev.bat only. Never chain dist.bat after dev.bat — dev is a blocking Electron process. When you want an installer, stop dev (Ctrl+C) and run scripts\dist.bat in a new command.

Or npm i then npm run dev. Installer: hawaldar-app/release/Hawaldar Setup 0.1.0.exe via scripts\dist.bat.

macOS / Linux

git clone https://github.com/A-G-U-P-T-A/hawaldar.git
cd hawaldar/hawaldar-app
chmod +x scripts/*.sh
./scripts/setup.sh
./scripts/dev.sh

Packaged output is hawaldar-app/release/ — .dmg/.zip on macOS, .AppImage/.deb on Linux. Run ./scripts/dist.sh only after stopping dev.

setup runs npm ci/npm i and restores the Electron binary via scripts/ensure-electron.mjs. dev skips that restore when the Electron binary is already on disk.

Typecheck

npm run typecheck

Packaged installer

dist runs typecheck, electron-vite build, and electron-builder, then restores Electron so npm run dev still works.

Electron uninstall after dist

electron-builder often removes node_modules/electron/path.txt and the dist binary. electron-vite then throws Error: Electron uninstall. Fix: npm run ensure-electron (also hooked from npm run dist and the setup/dist scripts). Daily dev skips the restore when electron.exe is already present.

Do not commit node_modules, release/, .env, or ~/.hawaldar data.
