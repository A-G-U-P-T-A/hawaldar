Building from source

git clone https://github.com/A-G-U-P-T-A/hawaldar.git
cd hawaldar/hawaldar-app
# Windows
scripts\setup.bat
scripts\dev.bat
# macOS / Linux
chmod +x scripts/*.sh
./scripts/setup.sh
./scripts/dev.sh

Node 22+ is required. setup runs npm ci/npm i and restores the Electron binary via scripts/ensure-electron.mjs.

Typecheck

npm run typecheck

Packaged installer

scripts\dist.bat
# or
./scripts/dist.sh

That runs typecheck, electron-vite build, and electron-builder, then restores Electron so npm run dev still works. Output is hawaldar-app/release/.

Electron uninstall after dist

electron-builder often removes node_modules/electron/path.txt and the dist binary. electron-vite then throws Error: Electron uninstall. Fix: npm run ensure-electron (also hooked from postinstall, npm run dist, and the setup/dev/dist scripts).

Do not commit node_modules, release/, .env, or ~/.hawaldar data.
