Hawaldar

A local Electron workstation for authorized reconnaissance and bounded proof-of-concept validation. Policy owns scope. Tools run only in Podman (or Docker if you already have it). Every intrusive PoC probe is approved in-app, one prompt per probe.

Not an exploit platform. There is no host shell for the model, no msfvenom, no credential dump, no SQL data extraction. HITL PoC probes refuse DELETE, data-mutating SQL, and cookie/storage exfiltration. Confirmed findings land in the Findings tab with reproduction steps.

What’s new in v0.1.0-beta.2

  • Splash with one logo, Poppins, and Material icons; Home; dark/light theme
  • Findings scoped to the engagement; unassigned chat is a first-class thread
  • DevTools stay closed unless HAWALDAR_DEVTOOLS=1
  • Engagement reports are structured PDFs, not a markdown dump
  • In-app PDF viewer via pdf.js (no Chromium PDF plugin / ERR_BLOCKED_BY_CLIENT)
