Install

Beta installers are attached to GitHub Releases (prerelease). Builds are unsigned until code-signing secrets are configured — Windows SmartScreen and macOS Gatekeeper will warn. That is expected.

Windows

  • Download Hawaldar Setup 0.1.x.exe (NSIS, x64). ia32 is not shipped (Electron 43).
  • Optional arm64 artifacts appear only when the release workflow produced them.
  • After install, open the app → Set up Podman. Windows needs WSL or Hyper-V. The installer does not install Podman.

macOS

  • Download the .dmg or .zip. CI prefers a universal (x64 + arm64) build when the macOS runner can produce it.
  • Unsigned / not notarized: right-click Open, or clear quarantine after you have verified the checksum from the release notes.
  • Then Set up Podman in the app (installs Podman and starts the VM).

Linux

  • AppImage or .deb for x64. arm64 Linux packages are not in the default matrix (too fragile on ubuntu-latest).
  • Install Podman from your distro (Hawaldar will not sudo-install packages).
