Getting started

Use Hawaldar only on systems you own or administer, with written permission, or under a contracted pentest. The first-run Legal page must be accepted before tools run.

1. Clone

git clone https://github.com/A-G-U-P-T-A/hawaldar.git
cd hawaldar/hawaldar-app

2. Node 22+

Check with node -v. Then:

scripts\setup.bat
scripts\dev.bat

On macOS/Linux: chmod +x scripts/*.sh && ./scripts/setup.sh && ./scripts/dev.sh.

3. Legal gate

Accept the in-app agreement. Decline quits. LICENSE remains English even if you change the UI language.

4. Provider and API key

Open Settings → Provider. Choose a provider, model, and API key. Keys are stored in ~/.hawaldar/settings.json (encrypted when the OS keychain is available).

5. Podman

Open Runtime and choose Set up Podman. Tools do not run on the host. See Podman.

6. Scope

Settings → Scope. Named hosts/IPs/CIDRs. Out-of-scope targets are blocked in code, not only in the prompt.
