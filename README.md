# Hawaldar

Local authorized **reconnaissance** workstation. Persistent engagement state, scoped policy, and isolated tool execution. Not an exploitation platform.

## Develop

Requires Node 20+.

```bash
npm install
npm run typecheck
npm run lint
npm test
```

Do not point this system at hosts you are not authorized to assess.
